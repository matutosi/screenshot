# Reset transparent background of an image

Reset transparent background of an image

## Usage

``` r
reset_transparent(path)
```

## Arguments

- path:

  A character string specifying the file path to the image to be
  processed.

## Value

The file path to the processed image.

## Examples

``` r
if (FALSE) { # \dontrun{
path <- "directory/image.png"
reset_transparent(path)
} # }
```
