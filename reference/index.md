# Package index

## Take screenshot

- [`screenshot()`](https://matutosi.github.io/screenshot/reference/screenshot.md)
  : Take a screenshot.
- [`install_screenshot()`](https://matutosi.github.io/screenshot/reference/install_screenshot.md)
  : Install command line screenshot for Windows.
- [`screenshot_exists()`](https://matutosi.github.io/screenshot/reference/screenshot_exists.md)
  : Find screenshot exec file.
- [`get_os()`](https://matutosi.github.io/screenshot/reference/get_os.md)
  : Get OS name

## Locate image

- [`locate_image()`](https://matutosi.github.io/screenshot/reference/locate_image.md)
  : Locate needle image position on a screenshot image.

- [`locate_ndl_in_hay()`](https://matutosi.github.io/screenshot/reference/locate_ndl_in_hay.md)
  :

  Locate needle image matrix position in a haystack_image matrix. Helper
  function for
  [`locate_image()`](https://matutosi.github.io/screenshot/reference/locate_image.md).

- [`crop_image()`](https://matutosi.github.io/screenshot/reference/crop_image.md)
  [`hay2needle()`](https://matutosi.github.io/screenshot/reference/crop_image.md)
  : Cut off a part of image from a whole image.

- [`display_corner()`](https://matutosi.github.io/screenshot/reference/display_corner.md)
  : Get display corner of screen

- [`display_size()`](https://matutosi.github.io/screenshot/reference/display_size.md)
  : Get the size of the display.

- [`compare_table()`](https://matutosi.github.io/screenshot/reference/compare_table.md)
  :

  Compare values within tow arrays or matrices. Helper function for
  [`locate_ndl_in_hay()`](https://matutosi.github.io/screenshot/reference/locate_ndl_in_hay.md).

- [`count_val_freq()`](https://matutosi.github.io/screenshot/reference/count_val_freq.md)
  :

  Helper function for
  [`compare_table()`](https://matutosi.github.io/screenshot/reference/compare_table.md).

- [`image2gray_matrix()`](https://matutosi.github.io/screenshot/reference/image2gray_matrix.md)
  :

  Convert cimg class into grayscale xy matrix. Helper function for
  [`locate_image()`](https://matutosi.github.io/screenshot/reference/locate_image.md).
  Use grayscale to Speed up and to simplify code.

- [`index2xy()`](https://matutosi.github.io/screenshot/reference/index2xy.md)
  :

  Convert array index into xy location in matrix. Helper function for
  [`locate_ndl_in_hay()`](https://matutosi.github.io/screenshot/reference/locate_ndl_in_hay.md).

- [`is_all_same()`](https://matutosi.github.io/screenshot/reference/is_all_same.md)
  :

  Helper function for
  [`locate_ndl_in_hay()`](https://matutosi.github.io/screenshot/reference/locate_ndl_in_hay.md).

- [`xy_pos()`](https://matutosi.github.io/screenshot/reference/xy_pos.md)
  :

  Get xy position of a value in a matrix Helper function for
  [`locate_ndl_in_hay()`](https://matutosi.github.io/screenshot/reference/locate_ndl_in_hay.md).
