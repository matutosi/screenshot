# Helper function for `locate_ndl_in_hay()`.

Helper function for
[`locate_ndl_in_hay()`](https://matutosi.github.io/screenshot/reference/locate_ndl_in_hay.md).

## Usage

``` r
is_all_same(ndl_mt, hay_mt, base_xy, tol_val = 0)
```

## Arguments

- ndl_mt, hay_mt:

  A matrix

- base_xy:

  A numeric pair of xy location.

- tol_val:

  A numeric of the tolerance of the comparison.

## Value

        A logical.
